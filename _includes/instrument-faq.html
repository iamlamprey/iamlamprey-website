FAQs

What is this product?

This is a virtual instrument - it plays recorded samples back when it receives a MIDI note from your DAW. Virtual instruments are the industry standard for high-quality, expressive playback.

Do I need a workstation (DAW)?

Yes - both versions of this instrument require both a workstation (DAW) like Ableton or Logic, as well as a sampler plugin (Kontakt or Rhapsody).

Do I need Kontakt?

There is a Kontakt and Rhapsody version. If you want to use the Kontakt version you will need the FULL (not free) version of Kontakt 5.5 or later.

Note: More recent versions of Kontakt (like 8+) may have compatibility issues and are untested. Use an older Kontakt (or Rhapsody).

What is Rhapsody?

Rhapsody is a free alternative to Kontakt, available for MacOS, Windows and Linux. Rhapsody only loads the Rhapsody version - it cannot load the Kontakt version of the instrument.

What is the difference between the Kontakt and Rhapsody versions?

The Kontakt versions came first so they're a bit outdated. In general I recommend using the Rhapsody version - it's free, more "modern" and includes additional controls like sampler-level adjustments and effects.

How do I use this in my DAW?

It depends on the DAW, but the general steps are:

  1. Install Kontakt / Rhapsody
  2. Install the instrument.
  3. Create an instrument track in your DAW - add Kontakt / Rhapsody.
  4. Load the instrument onto the track.
  5. Create (or record) a MIDI clip onto the timeline.

The MIDI information will then be sent to the instrument by your DAW - allowing you to hear the playback.
